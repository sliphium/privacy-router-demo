# PrivacyRouter 端云协同隐私守卫者 · 设计文档

日期：2026-11-11
状态：已确认，进入实现

## 1. 目标

让用户在享受云端大模型推理能力的同时，保证涉密数据不离开本机。系统在每次请求前判定敏感度，并按三档路由：

检测规则按「分级」组织，检测范围不随策略切换而缩小：

- `critical`（高敏）：命中即本地，任何策略下都不上云。包括身份证、密钥、学号、学生名单、家庭住址、心理、资助、处分、党团、合同、财务、人事、源代码、内部机密。
- `sensitive`（敏感）：参与评分与脱敏判定。包括姓名、成绩、宿舍、家长、手机、邮箱、内网地址。
- `normal`（一般）：仅影响评分。

策略只调整非高敏任务的路由严格度：

- `campus`（默认）：任何命中即本地，不走脱敏上云。
- `enterprise`：`critical` 仍强制本地，其余按阈值三档。

关键点：企业秋招、实习招聘场景中的学生简历、候选人名单同样受保护，学生隐私不会因为切到企业策略而失效。

| 档位 | 触发条件（enterprise 策略） | 去向 |
| --- | --- | --- |
| 本地 | 分数 ≥ localThreshold（默认 40）或严格模式下任意命中 | 本地 Ollama |
| 脱敏上云 | sanitizeThreshold（默认 10）≤ 分数 < localThreshold | 本地脱敏后调用云端 OpenAI 兼容 API |
| 直连上云 | 分数 < sanitizeThreshold | 云端 API |

校园强隐私模式下不进入「脱敏上云」档：只要命中任意规则即走本地。

## 2. 架构

```text
浏览器单页(public/)
   │ HTTP + SSE，仅同源、仅本机
   ▼
Node 零依赖服务(server/)
   ├── detector   规则证据链打分，可选 Ollama 语义复核
   ├── sanitizer  实体占位符替换 / 响应回填
   ├── router     三档决策、脱敏后复检、fail-closed
   ├── providers  ollama / cloud / mock
   └── audit      本地 JSONL 审计（不外发）
```

部署边界：服务默认只监听 `127.0.0.1`。云端 API Key 只存在后端进程与 `config.json`（权限 600），`GET /api/config` 仅返回掩码。

## 3. 检测器

规则分两类。

实体类（可脱敏）：PEM 私钥、云厂商/代码托管平台密钥、数据库连接串、身份证号（校验位验证）、银行卡号（Luhn 校验）、手机号、邮箱、内网 IP、学号/考生号（需上下文）、宿舍床位、高熵随机串。

语义类（不可脱敏，命中即升级）：学生姓名与名单、资助与困难认定、处分与违纪、学生名单与档案、党团与政审材料、学业与奖惩数据、家庭住址、家长/监护人信息、合同与法务、财务与经营数据、人事与薪酬、内部机密/未公开信息、完整代码块、内部域名。

语境类：任务描述同时出现学生主体（学生/同学/班级/辅导员/家长等）与隐私字段（名字/住址/电话/名单/表格/Excel/信息等）时，即使没有实体，也按涉敏任务处理。

心理与健康类（最高级别）：心理测评、咨询、危机干预、抑郁、焦虑、病史、残疾等，命中后只在本机处理，且对外展示与审计全部隐去细节。

评分：取最高权重为基分，其余命中按 0.18 系数累加，命中 3 类及以上追加 8 分，封顶 100。每条命中都携带类型、严重级、权重、命中片段与理由，供前端裁决卡展示。

## 4. 隐私链路

1. 检测本次请求携带的全部上下文（最多 12 条消息），不只看最后一条。历史中任意一条命中，都按最高级别处理：即使第一句涉密、第二句只是“帮我总结成三点”，整个请求仍会留在本地。
2. 判定为「脱敏上云」时，对所有消息中的实体分别替换为带消息前缀的占位符（如 `<M2_PHONE_1>`），再整体复检分数，复检仍达本地阈值则升级为本地处理。
3. 云端返回后，用掩码表回填；流式期间显示占位符，结束时下发回填全文。
4. 审计默认最小化：不落盘外发原文或脱敏文本，只记录 SHA-256 指纹、字符长度、命中类型与决策依据；本地处理记录为空。这样审计不会变成第二个敏感数据仓库。
5. Fail-closed：涉密任务遇到本地模型不可达时直接阻断，不静默改走云端。云端失败时默认允许本地兜底（方向更安全），可关闭。
6. 心理与健康类命中：对外证据统一替换为「个人健康与心理信息」，不返回具体词、原文或命中片段；审计同样只留类别与「细节已隐去」，不落盘细节。
7. 本地应答注入隐私约束：不复述姓名、学号、联系方式、住址、成绩、健康与心理细节，用「该同学」「相关材料」指代，不对学生做标签化判断。
8. 高敏兜底：`critical` 级命中不受策略切换影响，强制本地处理，并在裁决卡与审计中标记 `criticalHit`。
9. 新建对话会清空前端上下文；否则涉密历史会持续把后续请求留在本地。
10. 旧版本审计日志可能已包含明文外发内容，升级后应通过界面「清空」或删除 `data/audit.jsonl` 清理。

## 5. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/chat` | SSE 流式对话，事件：meta / delta / final / done / error |
| GET | `/api/config` | 读取配置（Key 掩码） |
| PUT | `/api/config` | 更新配置，掩码值视为不修改 |
| GET | `/api/health` | Ollama 与云端可用性、当前模式 |
| GET | `/api/audit` | 最近审计记录 |
| POST | `/api/audit/clear` | 清空审计 |

配置优先级：环境变量 > `config.json` > 内置默认值。演示模式下本地与云端均由 Mock Provider 应答，界面明确标注，不冒充真实模型。

## 6. 界面

单页三栏：对话流（含路由徽标与流式输出）、实时裁决卡（评分环、命中证据、脱敏对照）、策略配置与审计面板。顶栏展示本地/云端状态灯、演示模式与严格模式开关。窄屏自动堆叠。

## 7. 错误处理

- 本地不可达 + 涉密：HTTP 200 建立 SSE 后下发 `error` 事件，审计记为 blocked。
- 云端不可达：允许本地兜底则改走本地并改写 meta；否则阻断。
- 上游超时默认 300 秒，可在界面「请求超时（秒）」调整，范围 5–1800 秒；本地推理模型（如 DeepSeek-R1）较慢时应适当调大。流中断保留已生成内容并记录错误。
- 请求体超过 1 MB、静态路径穿越、非法 JSON 一律 4xx。

## 8. 验证

- `node:test`：检测器各规则与阈值边界、脱敏回填、三档路由、严格模式、fail-closed、配置掩码。
- 端到端：真实启动服务，三档请求分别断言 SSE meta 决策、占位符外发、审计落盘。
- 界面：浏览器自动化截图确认三栏渲染与徽标。

## 9. 非目标

不做提示词注入防护、不做多云厂商适配层、不做账号体系。以上留作后续迭代。
