# PrivacyRouter 端云协同隐私守卫者 · 设计文档

日期：2026-11-11
状态：已确认，进入实现

## 1. 目标

让用户在享受云端大模型推理能力的同时，保证涉密数据不离开本机。系统在每次请求前判定敏感度，并按三档路由：

检测规则按「分级」组织，检测范围不随策略切换而缩小：

- `critical`（高敏）：命中即本地，任何策略下都不上云。包括身份证、密钥、学号、学生名单、家庭住址、心理、资助、处分、党团、合同、财务、人事、源代码、内部机密。
- `sensitive`（敏感）：参与评分与脱敏判定。包括姓名、成绩、宿舍、家长、手机、邮箱、内网地址。
- `normal`（一般）：仅影响评分。

策略只调整非高敏任务的路由严格度：

- `campus`（默认）：任何命中即本地，不走脱敏上云。
- `enterprise`：`critical` 仍强制本地，其余按阈值三档。

关键点：企业秋招、实习招聘场景中的学生简历、候选人名单同样受保护，学生隐私不会因为切到企业策略而失效。

| 档位 | 触发条件（enterprise 策略） | 去向 |
| --- | --- | --- |
| 本地 | 分数 ≥ localThreshold（默认 40）或严格模式下任意命中 | 本地 Ollama |
| 脱敏上云 | sanitizeThreshold（默认 10）≤ 分数 < localThreshold | 本地脱敏后调用云端 OpenAI 兼容 API |
| 直连上云 | 分数 < sanitizeThreshold | 云端 API |

校园强隐私模式下不进入「脱敏上云」档：只要命中任意规则即走本地。

## 2. 架构

```text
浏览器单页(public/)
   │ HTTP + SSE，仅同源、仅本机
   ▼
Node 零依赖服务(server/)
   ├── detector   规则证据链打分，可选 Ollama 语义复核
   ├── sanitizer  实体占位符替换 / 响应回填
   ├── router     三档决策、脱敏后复检、fail-closed
   ├── providers  ollama / cloud / mock
   └── audit      本地 JSONL 审计（不外发）
```

部署边界：服务默认只监听 `127.0.0.1`。云端 API Key 只存在后端进程与 `config.json`（权限 600），`GET /api/config` 仅返回掩码。

## 3. 检测器

规则分两类。

实体类（可脱敏）：PEM 私钥、云厂商/代码托管平台密钥、数据库连接串、身份证号（校验位验证）、银行卡号（Luhn 校验）、手机号、邮箱、内网 IP、学号/考生号（需上下文）、宿舍床位、高熵随机串。

语义类（不可脱敏，命中即升级）：学生姓名与名单、资助与困难认定、处分与违纪、学生名单与档案、党团与政审材料、学业与奖惩数据、家庭住址、家长/监护人信息、合同与法务、财务与经营数据、人事与薪酬、内部机密/未公开信息、完整代码块、内部域名。

语境类：任务描述同时出现学生主体（学生/同学/班级/辅导员/家长等）与隐私字段（名字/住址/电话/名单/表格/Excel/信息等）时，即使没有实体，也按涉敏任务处理。

心理与健康类（最高级别）：心理测评、咨询、危机干预、抑郁、焦虑、病史、残疾等，命中后只在本机处理，且对外展示与审计全部隐去细节。

评分：取最高权重为基分，其余命中按 0.18 系数累加，命中 3 类及以上追加 8 分，封顶 100。每条命中都携带类型、严重级、权重、命中片段与理由，供前端裁决卡展示。

## 4. 隐私链路

1. 检测本次请求携带的全部上下文（最多 12 条消息），不只看最后一条。历史中任意一条命中，都按最高级别处理：即使第一句涉密、第二句只是“帮我总结成三点”，整个请求仍会留在本地。
2. 判定为「脱敏上云」时，对所有消息中的实体分别替换为语义化占位符（如 `[手机号1#a7c3]`，`#` 后为本次请求标记），再整体复检分数，复检仍达本地阈值则升级为本地处理。
3. 云端返回后，用掩码表回填；流式期间显示占位符，结束时下发回填全文。
4. 审计默认最小化：不落盘外发原文或脱敏文本，只记录 SHA-256 指纹、字符长度、命中类型与决策依据；本地处理记录为空。这样审计不会变成第二个敏感数据仓库。
5. Fail-closed：涉密任务遇到本地模型不可达时直接阻断，不静默改走云端。云端失败时默认允许本地兜底（方向更安全），可关闭。云端在运行期失败（鉴权失败、模型不存在、连接中断）且尚未输出任何内容时，下发 `fallback` 事件并自动改用本地重试；一旦已产生输出则直接报错，避免拼接两个模型的回答。本地失败绝不反向降级到云端，`allowDegradeToCloud` 不参与涉密路由。
6. 心理与健康类命中：对外证据统一替换为「个人健康与心理信息」，不返回具体词、原文或命中片段；审计同样只留类别与「细节已隐去」，不落盘细节。
7. 本地应答注入隐私约束：不复述姓名、学号、联系方式、住址、成绩、健康与心理细节，用「该同学」「相关材料」指代，不对学生做标签化判断。
8. 高敏兜底：`critical` 级命中不受策略切换影响，强制本地处理，并在裁决卡与审计中标记 `criticalHit`。
9. 新建对话会清空前端上下文；否则涉密历史会持续把后续请求留在本地。
10. 旧版本审计日志可能已包含明文外发内容，升级后应通过界面「清空」或删除 `data/audit.jsonl` 清理。
11. 会话粘性：服务端按 `sessionId` 记录会话是否曾出现敏感内容；一旦标记，后续请求即使客户端只发普通消息也继续强制本地，直到新建对话触发 `/api/session/reset`。状态保留 2 小时。
12. 强制脱敏上云：用户在本地处理结果上可点击「脱敏后用云端重试」。只有当全部命中项都可遮掩（实体类）时才允许，且会明确提示「任务语义仍会外发」；心理、资助、处分、合同等无法用占位符遮掩的语义级敏感内容一律阻断。
13. 心理危机分级转介：命中自杀、自伤、轻生等高风险词时，强制本地、不调用模型，返回固定转介话术；中风险（抑郁、失眠、情绪低落）走本地并在界面提示资源；高风险内容不落审计原文，只记 `crisisLevel`。默认推荐全国心理援助热线 12356，并提示“如当地未开通，请拨打 120 / 110”，不写死任何地区号码。学校心理中心与辅导员由 `config.crisis` 可选填写，并由学校审核。
14. 审计链式哈希：每条记录带 `prevHash` 和 `hash`，篡改或删除中间记录会在校验时暴露；`GET /api/audit/verify` 返回链是否完整、断点位置。旧记录无哈希时记为 legacy，不参与断链判断。
15. 强制脱敏上云只发送当前 user 消息，不带历史助手文本：助手通用建议里出现“心理”“资助”等词时，不会因此阻断本次上云；发送前通过 `/api/preview` 展示云端将收到的完整文本，用户确认后才发送。

## 5. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/chat` | SSE 流式对话，事件：meta / fallback / delta / final / done / error；可选 `sessionId`、`forceSanitized` |
| GET | `/api/config` | 读取配置（Key 掩码） |
| PUT | `/api/config` | 更新配置，掩码值视为不修改 |
| GET | `/api/health` | Ollama 与云端可用性、当前模式 |
| GET | `/api/audit` | 最近审计记录 |
| POST | `/api/audit/clear` | 清空审计 |
| GET | `/api/audit/verify` | 校验审计链完整性 |
| POST | `/api/preview` | 返回脱敏后云端将收到的文本，用于发送前确认 |
| POST | `/api/session/reset` | 清除指定会话的涉密粘性 |
| POST | `/api/scan-file` | 本地扫描 xlsx/xls/csv/tsv/docx/pdf/png/jpg/webp，返回统计与脱敏文件 |

配置优先级：环境变量 > `config.json` > 内置默认值。演示模式下本地与云端均由 Mock Provider 应答，界面明确标注，不冒充真实模型，且语义复核不生效（`/api/health` 返回 `semanticReviewEffective: false`）。

云端 `baseUrl` 支持三种写法：裸域名（`https://api.deepseek.com`）、带版本段（`https://api.deepseek.com/v1`）与完整端点（`.../v1/chat/completions`），服务端统一解析为实际请求地址。`/api/health` 的 `cloud` 同时返回 `configured`（是否填了 Key）、`valid`（地址与模型名是否都能解析）、`endpoint`（实际调用的完整地址）与 `reason`（不可用原因），`availability.cloud` 也以 `valid` 为准，不再“有 Key 就算可用”。云端显式填空的模型名或地址会保留为空并报配置无效，不会静默回退成默认值。

语义复核（`semanticReview`）在规则未命中但分数仍需复核时调用本地模型，单次超时取 `timeoutMs` 上限 180 秒（1.5b 实测 30–80 秒），复核耗时随 `meta.semantic.durationMs` 返回。SSE 连接默认每 15 秒发送 `: ping` 注释帧，避免长耗时模型调用被中间层判定为断连；心跳间隔可通过 `createApp({ sseHeartbeatMs })` 调整。

`config.crisis` 提供 `enabled`、`hotline`、`counselingCenter`、`counselorContact`、`message`。联系方式默认留空，避免内置未经审核的号码；留空时固定话术会提示使用方补全。

### 文件扫描

`POST /api/scan-file` 接收 `{ filename, contentBase64 }`，文件解码后限制 8 MB。

表格文件（xlsx/xls/csv/tsv）用 SheetJS 解析工作表，逐单元格调用检测器，返回总单元格数、命中数、高敏数、最高分、命中类型、路由建议，以及把所有可脱敏单元格替换为占位符后的新文件（base64，统一输出 xlsx）。单表最多 2000 行、80 列、8 个工作表。表头含「姓名/名字/联系人」的列会强制按姓名识别，表头含「学号/考生号/学籍号」的列会强制按学号识别。

文档文件（docx/pdf）分别用 mammoth 与 pdf-parse 提取纯文本，整篇检测后返回字符数、命中数、高敏数、最高分、命中类型、路由建议，以及脱敏后的 txt（base64）。单篇最多 200000 字符；PDF 页码标记会被清理。docx 会额外解析表格单元格、页眉和页脚文字；脚注、批注、文本框和图片中的文字暂不提取。扫描版 PDF 没有文本层，会明确提示需要 OCR，而不是静默返回空结果。

图片文件（png/jpg/jpeg/webp）用 tesseract.js 做中英文 OCR，语言包 `tessdata/chi_sim.traineddata` 随项目内置，不上传到外部服务。OCR 文本会合并中文字符间空格，再整篇检测并导出脱敏 txt。扫描版 PDF 暂不自动转图片，仍提示用户截图后上传。

原文件与提取内容不上传云端，审计只记录文件名哈希与统计。

## 6. 界面

单页三栏：对话流（含路由徽标与流式输出）、实时裁决卡（评分环、命中证据、脱敏对照）、策略配置与审计面板。顶栏展示本地/云端状态灯、演示模式与严格模式开关。对话面板支持点击或直接拖入表格、文档与图片文件（xlsx/xls/csv/tsv/docx/pdf/png/jpg/jpeg/webp）进行本地扫描。命中高风险心理内容时，裁决卡顶部显示红色转介横幅；中风险显示黄色提示。脱敏上云前会展示「云端将收到」的完整文本，确认后才发送。窄屏自动堆叠。

## 7. 错误处理

- 本地不可达 + 涉密：HTTP 200 建立 SSE 后下发 `error` 事件，审计记为 blocked。
- 云端不可达：请求前探活失败则直接改走本地并改写 meta；请求中失败且尚未输出内容则下发 `fallback` 事件后改用本地重试，审计记录 `route=local`、`degraded=true` 与 `fallbackFrom`；已输出内容或本地也不可用则下发 `error`。
- 云端鉴权、模型名、端点错误会按状态码给出可操作提示（401/403 指向 Key，404 指向 baseUrl 与模型名，429 指向限流或余额）。
- 上游超时默认 300 秒，可在界面「请求超时（秒）」调整，范围 5–1800 秒；本地推理模型（如 DeepSeek-R1）较慢时应适当调大。流中断保留已生成内容并记录错误。
- 普通接口请求体超过 1 MB、文件扫描请求超过 12 MB（解码后文件超过 8 MB）、静态路径穿越、非法 JSON 一律 4xx。

## 8. 验证

- `node:test`：检测器各规则与阈值边界、脱敏回填、三档路由、严格模式、fail-closed、配置掩码。
- 端到端：真实启动服务，三档请求分别断言 SSE meta 决策、占位符外发、审计落盘。
- 界面：浏览器自动化截图确认三栏渲染与徽标。
