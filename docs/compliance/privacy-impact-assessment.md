# PrivacyRouter 隐私影响评估（PIA）模板

> 本文件是模板，需由学校信息化部门、法务/合规负责人、心理中心共同审核后使用。
> 文中不包含具体法律条款编号，避免误引；请按学校所在地法规补充。

## 1. 系统用途

PrivacyRouter 部署在学生干部的本机，用于在调用大模型前判断内容敏感度：

- 涉密内容留在本机，由本地 Ollama 处理
- 通用内容可按配置调用云端模型
- 用户可主动选择“脱敏后交给云端”，并先查看云端将收到的内容

## 2. 数据流

| 环节 | 数据 | 去向 |
| --- | --- | --- |
| 输入 | 用户输入的文字、上传的表格、文档或图片 | 仅发送到本机 Node 服务 |
| 检测 | 敏感实体、关键词、表格单元格、文档文本、图片 OCR 文本 | 本机内存，不落盘 |
| 本地处理 | 完整原文 | 本机 Ollama（127.0.0.1） |
| 云端直连 | 原文 | 云端模型服务商 |
| 脱敏上云 | 实体替换为占位符后的文本 | 云端模型服务商，原文不回填给云端 |
| 审计 | 路由、分数、命中类型、SHA-256 指纹、字符长度 | 本机 `data/audit.jsonl`，链式哈希 |
| 表格扫描 | 单元格统计、脱敏后文件 | 本机，原文件不离开设备 |
| 文档扫描 | 提取文本统计、脱敏后文本 | 本机，原文件不离开设备 |

## 3. 数据分类

- 高敏：身份证、银行卡、密钥、学号、学生名单、家庭住址、心理与健康、资助、处分、党团材料、合同、财务、源代码
- 敏感：单个姓名、成绩、宿舍、家长信息、手机号、邮箱、内网地址
- 一般：普通通知、课程讨论、公开信息

## 4. 主要风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 云端服务商留存原文 | 涉密默认本地；脱敏上云前展示外发内容并二次确认 |
| 本地日志成为二次泄露源 | 审计不存原文，只存哈希与统计；链式哈希防篡改 |
| 多轮上下文把第一句带上去 | 检测全部上下文；会话粘性，涉密会话后续强制本地 |
| 用户通过空格、零宽字符绕过检测 | 紧凑二次检测，命中即本地 |
| 心理危机内容被模型不当回应 | 高风险固定话术，不调用模型；中风险本地提示资源 |
| 表格/文档/图片附件漏检 | 表格逐单元格检测，表头识别姓名/学号列；docx/pdf 提取正文、表格、页眉页脚后整篇检测；图片用本机 OCR 提取文字后检测；导出脱敏文件 |
| 服务被局域网访问 | 默认只监听 127.0.0.1；如需多人使用，必须加认证与 HTTPS |

## 5. 数据留存

- 审计保留期限：由学校确定，建议不超过 90 天
- 审计内容：不含原文，含请求哈希、路由、命中类型、耗时
- 删除方式：界面「清空」或删除 `data/audit.jsonl`
- 本地模型与云端服务商的留存策略：需单独确认并写入告知书

## 6. 第三方

- 云端模型服务商：需确认其数据使用、留存、跨境传输政策
- 本地模型：Ollama 在本机运行，不产生外部请求
- 表格解析：SheetJS 在本机运行，不上传文件
- 文档解析：mammoth（docx）、pdf-parse（pdf）、JSZip（页眉页脚）均在本机运行，不上传文件
- 图片 OCR：tesseract.js 在本机运行，中文语言包随项目内置，不上传图片

## 7. 残余风险

- 规则引擎无法覆盖所有隐晦表达、拼音、图片、编码内容
- 脱敏只能遮掩实体，不能遮掩任务语义
- 本地小模型可能给出不准确回复
- 用户主动选择云端直连时，原文仍会离开设备
